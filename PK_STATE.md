## 8c. FACE TUNING GUIDE (pk_avatar.js — all knobs in ONE file)
Goal: owner wants the face posture/expression improved over time. Any
future session tuning the face should read this first and report changes.
- IMAGES (owner-generated via Gemini edit of face_base.png — rules: same
  face/style/framing, edit mouth only):
  face_base.png (closed), mouth_a.png (big open "අ"), mouth_o.png
  (small round "ඔ"), mouth_i.png (wide thin "ඉ"), mouth_smile.png
  (gentle closed smile). All have a Gemini watermark bottom-right —
  hidden by coverWatermark() in code (do NOT need image editing).
- CANVAS FIT: `var s = Math.max(W/b.width, H/b.height) * 1.07;` — COVER
  mode (prevents green bands on a square canvas). If too much crop →
  tune 1.07 down to 1.05.
- TALK SPEED: speakSnippet() per-shape durations — vowels ~140-195ms,
  M ~95-125ms, closed ~75-110ms (punctuation pauses longer). Tune these
  numbers to change speed.
- TALK LENGTH: only first ~60 chars of the reply (text.slice(0,60)) —
  by design (soft). Raise if owner wants longer talking.
- REPLY TRIGGER: chat_server.py CHAT_HTML → send() function → the
  PKFace.speak line AFTER the full 2-line addMsg(...) statement
  (data.output = reply text).
- SMILE: smile(2200) fires after speech ends; smileUntil logic in pickKey().
- BLINK: random 2.6–6s, 150ms; drawLid() + CAL.eyes calibration.
- BREATHING: scale 1+0.012*sin(t/750); HEAD BOB while acting:
  X sin(t/470)*0.35, Y sin(t/320)*0.45.
- CLICK: canvas click toggles .big class (big stays during chat —
  non-blocking overlay removed by design).
- VOICE: pk_v12.js `u.rate = 0.95; u.pitch = 0.7;` (male voice; raise
  pitch toward 0.8/0.9 if too deep).
- SILA: face layer does NOT touch sila/ — "kill someone" must stay blocked
  after any face change (test it).

## 9. Gotchas / lessons learned (do not repeat)
- INSTANCE vs ROOT: fix the decision layer + STANDARD TEST 3 (owner's rule).
- CHAT_HTML edits: the send() reply handler's addMsg(...) statement SPANS
  2 LINES — insert new lines AFTER the full statement, never inside it.
  One broken line in CHAT_HTML kills the whole script (send button dead,
  SyntaxError at that line). Always screenshot the surrounding code before
  inserting into CHAT_HTML.
- Full-file replaces can silently drop earlier small fixes — before
  replacing a whole file, list its recent one-line fixes and re-add them.
- Square canvas + landscape image: Math.min = letterbox bands (green
  pulses with breathing); Math.max = cover (crops edges — correct here).
- Service Worker can serve stale assets → cache-bust (?v=2) + Ctrl+Shift+R;
  DevTools "Disable cache" for deep tests.
- DevTools Console: paste blocked until typing "allow pasting"; Sinhala
  text gets mangled in console — use English test strings like
  PKFace.speak("aaa ooo eee").
- Console/log lines (like POST /ask 520) are NOT Google-searchable — read
  them as our app's own logs.
- Gemini image edits always carry a bottom-right watermark — cover it in
  code (coverWatermark()), don't fight the images.
- NEVER paste large data (>50KB) into chat — move files via repo.
- SILA lock scans ONLY user input (+ history), NEVER injected text.
- Face/Avatar js must be self-contained; never edit other js files for it.
- NEVER create a .js file containing HTML (past mistake: 170 errors).
- Video files cannot be sent to chat — record, pause on frame, screenshot.
- Render free tier sleeps after 15 min → wake app before PWABuilder runs.
- Find&Replace: per-file Ctrl+H only; prefer full-file paste or exact
  single-line replace (Home → Shift+End).
- Browser caches pk_v12.js / pk_avatar.js / face images → Ctrl+Shift+R.
- /manifest (SILA) vs /manifest.json (PWA) — keep distinct.
- git: checkpoint commit before risky changes; Render Rollback for
  deployed mistakes; VS Code search shows docs matches too — real tests
  happen in the live app.
- debug_l1.py: dev debug script (harmless — can stay or delete later).
